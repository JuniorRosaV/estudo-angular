VS Code — Atalhos

  Edição básica
    Ctrl + C — copiar
    Ctrl + X — recortar
    Ctrl + V — colar
    Ctrl + Z — desfazer
    Ctrl + Y — refazer
    Ctrl + S — salvar arquivo
    Ctrl + Shift + S — salvar como
    Ctrl + K, S — salvar todos os arquivos
    Ctrl + A — selecionar tudo
    Ctrl + F — pesquisar no arquivo
    Ctrl + H — substituir no arquivo
    Ctrl + G — ir para uma linha específica
    Ctrl + P — pesquisar/abrir arquivo pelo nome
    Ctrl + W — fechar editor
    Ctrl + Shift + T — reabrir editor fechado

  Linhas e seleção
    Shift + Alt + ↓ — duplicar linha para baixo
    Shift + Alt + ↑ — duplicar linha para cima
    Alt + ↓ — mover linha para baixo
    Alt + ↑ — mover linha para cima
    Shift + Alt + ↓ — copiar linha para baixo
    Shift + Alt + ↑ — copiar linha para cima
    Shift + Delete — excluir linha
    Ctrl + Shift + K — excluir linha
    Home — início da linha
    End — fim da linha
    Ctrl + Home — início do arquivo
    Ctrl + End — fim do arquivo
    Shift + Home — selecionar até o início da linha
    Shift + End — selecionar até o fim da linha
    Ctrl + Shift + ← — selecionar palavra anterior
    Ctrl + Shift + → — selecionar próxima palavra
    Ctrl + ← — mover uma palavra para esquerda
    Ctrl + → — mover uma palavra para direita

  Pesquisa
    Ctrl + F — pesquisar
    Ctrl + H — substituir
    Ctrl + Shift + F — pesquisar em todos os arquivos
    Ctrl + Shift + H — substituir em todos os arquivos
    F3 — próxima ocorrência
    Shift + F3 — ocorrência anterior
    Alt + Enter — selecionar todas as ocorrências encontradas
    Ctrl + D — selecionar próxima ocorrência igual
    Ctrl + K, Ctrl + D — pular a ocorrência atual e selecionar a próxima

  Multicursor
    Alt + Clique — adicionar outro cursor
    Ctrl + Alt + ↑ — adicionar cursor acima
    Ctrl + Alt + ↓ — adicionar cursor abaixo
    Ctrl + U — desfazer último cursor
    Ctrl + Shift + L — selecionar todas as ocorrências da seleção
    Ctrl + D — selecionar próxima ocorrência igual

  IntelliSense / Código
    Ctrl + Space — abrir sugestões
    Ctrl + Shift + Space — mostrar parâmetros da função
    Ctrl + . — Quick Fix / sugestões de correção
    F12 — ir para definição
    Ctrl + F12 — ir para implementação
    Alt + F12 — visualizar definição
    Shift + F12 — encontrar referências
    F2 — renomear símbolo
    Ctrl + K, Ctrl + I — mostrar informações rápidas
    Ctrl + Shift + O — ir para símbolo no arquivo
    Ctrl + T — pesquisar símbolo no workspace

  Formatação
    Shift + Alt + F — formatar documento
    Ctrl + K, Ctrl + F — formatar seleção
    Ctrl + K, Ctrl + X — remover espaços em branco no final

  Comentários
    Ctrl + K, Ctrl + C — adicionar comentário
    Ctrl + K, Ctrl + U — remover comentário
    Ctrl + ; — comentar/descomentar linha
    Shift + Alt + A — comentário em bloco

 Terminal
    Ctrl + ' — abrir/fechar terminal
    Ctrl + Shift + ` — criar novo terminal
    Ctrl + Shift + C — abrir terminal externo
    Ctrl + J — abrir/fechar painel
    Ctrl + Shift + P — abrir Command Palette

  Explorer / Interface
    Ctrl + B — mostrar/ocultar barra lateral
    Ctrl + Shift + E — Explorer
    Ctrl + Shift + F — pesquisa
    Ctrl + Shift + G — Source Control / Git
    Ctrl + Shift + D — Run and Debug
    Ctrl + Shift + X — Extensions
    Ctrl + Shift + H — Search and Replace
    Ctrl + Shift + J — painel de busca
    Ctrl + " — mostrar/ocultar terminal
    F11 — tela cheia
    Ctrl + = — aumentar zoom
    Ctrl + - — diminuir zoom
    Ctrl + 0 — resetar zoom

  Abas / Editores
    Ctrl + Tab — alternar entre arquivos abertos
    Ctrl + 1 — primeiro grupo de editor
    Ctrl + 2 — segundo grupo
    Ctrl + 3 — terceiro grupo
    Ctrl + W — fechar aba
    Ctrl + K, F — fechar grupo de editor
    Ctrl + Shift + T — reabrir aba fechada
    Ctrl + PageUp — aba anterior
    Ctrl + PageDown — próxima aba
    Ctrl + K, ← — mover foco para grupo anterior
    Ctrl + K, → — mover foco para próximo grupo

  Dividir editor
    Ctrl + \ — dividir editor
    Ctrl + 1 — focar primeiro grupo
    Ctrl + 2 — focar segundo grupo
    Ctrl + 3 — focar terceiro grupo
    Ctrl + K, ← — grupo à esquerda
    Ctrl + K, → — grupo à direita
    Ctrl + K, ↑ — grupo acima
    Ctrl + K, ↓ — grupo abaixo
    
  Debug
    F5 — iniciar/continuar debug
    F9 — adicionar/remover breakpoint
    F10 — executar próxima linha
    F11 — entrar na função
    Shift + F11 — sair da função
    Shift + F5 — parar debug
    Ctrl + Shift + F5 — reiniciar debug

  Executar
    F5 — executar/debug
    Ctrl + F5 — executar sem debug
    Ctrl + Shift + F5 — reiniciar execução
    Shift + F5 — parar execução

  Navegação
    Ctrl + P — Quick Open
    Ctrl + Shift + P — Command Palette
    Ctrl + G — ir para linha
    Ctrl + T — pesquisar símbolos
    Ctrl + Shift + O — símbolos do arquivo
    F12 — definição
    Shift + F12 — referências
    Alt + ← — voltar
    Alt + → — avançar
    Ctrl + M — alternar foco entre editor e controle de acessibilidade

  Git / Source Control
    Ctrl + Shift + G — abrir Source Control
    Ctrl + Enter — commit
    Ctrl + Shift + G — painel Git
    F7 — próxima alteração
    Shift + F7 — alteração anterior

  Comandos importantes
    Ctrl + Shift + P — Command Palette
    Ctrl + P — Quick Open
    Ctrl + , — abrir configurações
    Ctrl + K, Ctrl + S — abrir atalhos de teclado
    Ctrl + K, Ctrl + O — abrir pasta
    Ctrl + K, Ctrl + T — selecionar tema
    Ctrl + Shift + P → Developer: Reload Window — recarregar VS Code
